# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |

## Reporting a vulnerability

This is a client-side generator with no backend, but supply-chain and
generated-output integrity still matter.

- **Do not** open a public issue for sensitive reports.
- Email the maintainer (see GitHub profile) with:
  1. What you found and where (`file:line` if possible)
  2. Steps to reproduce
  3. What you think the impact is

You will get a response within **7 days**. If confirmed, a fix and credit
will follow; please allow **90 days** coordinated disclosure before publishing
details.
